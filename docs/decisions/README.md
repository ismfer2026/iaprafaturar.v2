# Architecture Decision Records

Toda decisão estrutural do iaprafaturar v2 deve ser registrada aqui antes de virar código.

## Formato obrigatório

Cada ADR deve conter:

1. **Contexto**
2. **Opções consideradas**
3. **Decisão**
4. **Consequências**

## Regra

Se uma decisão altera arquitetura, deploy, monorepo, dados, contratos, eventos, auth, observabilidade, WhatsApp ou billing, ela precisa de ADR.
